# Правовая защита Qoldan: что сделано, что проверено, что осталось

Редакция от 14 ноября 2026. Это технический отчёт, а не юридическое заключение: тексты документов
составлены по фактам из кода и должны быть проверены юристом по законодательству Республики Казахстан.

## 1. Что сделано в коде

- Страницы `/legal`, `/legal/privacy`, `/legal/terms`, `/legal/returns`, `/legal/cookies`.
- Уведомление о cookie (`components/CookieNotice.tsx`): честное, без «принять всё», потому что
  необязательных cookie в проекте нет.
- Строка согласия перед кнопкой отправки во всех 11 формах основного клиента и в форме жилья
  (`components/ConsentNote.tsx`, три языка).
- Для проверки бизнес-профиля (БИН, телефон) — обязательный чекбокс; сервер отклоняет запрос без
  `consent: true`.
- `scripts/test-legal.mjs`: падает, если появилась таблица с данными без описания в политике, если у
  формы нет строки согласия или отсутствует страница. Показывает незаполненные заглушки.

## 2. Заполнить перед запуском

Видны на страницах жёлтой отметкой; список выводит `node --experimental-strip-types scripts/test-legal.mjs`.

- `lib/legal.ts`: наименование оператора, БИН/ИИН, юридический адрес, e-mail для запросов.
- `app/legal/privacy/page.tsx`: срок удаления данных после запроса (дней).

## 3. Вопросы к юристу (код их не решает)

1. **Хранение и передача за границу.** Данные лежат в облачной базе и хранилище файлов хостинг-платформы
   (Cloudflare D1/R2), серверы могут быть вне Казахстана. Проверить требования к хранению баз
   персональных данных и к трансграничной передаче, при необходимости — перенос или уведомления.
   **Обновление 19.11.2026:** по поправкам (Закон № 326-VIII от 24.06.2026) с 25.08.2026 персональные данные
   должны храниться на территории РК; это, вероятно, блокирует публичный запуск на текущей платформе. Варианты и
   источники — [INFRASTRUCTURE.md](INFRASTRUCTURE.md).
2. **Языки.** Для потребителей в РК документы обычно нужны на казахском и русском. Сейчас документы
   только на русском; баннер и строка согласия трёхъязычные (казахский текст проверить носителем).
3. **Согласие.** Сейчас согласие конклюдентное (строка у формы) плюс явный чекбокс для проверки бизнеса.
   Журнала согласий нет (нет таблицы и метки времени). Если нужен явный чекбокс при входе и
   первой публикации или журнал — потребуется миграция БД (не применялась).
4. **Права субъектов данных.** Есть самообслуживание: экспорт всех данных в JSON и удаление аккаунта в
   профиле (`/api/account/export`, `DELETE /api/account`, тест `scripts/test-account.mjs`). Журнал модерации
   сохраняется обезличенным. Вопрос юристу: допустимо ли хранить обезличенный журнал и срок его хранения.
5. **Регистрация оператора** и назначение ответственного за защиту данных, если требуется.
6. **Оферта.** Подсудность, пределы ответственности, возрастные ограничения, специальные нормы для
   жилья, аренды и продажи животных.

## 4. Аудит минимизации данных («Без лишних данных»)

| Данные | Нужны? | Наблюдение и рекомендация |
|---|---|---|
| Телефон в объявлении | Да, как контакт | Виден гостям (страница объявления: `tel:` и WhatsApp, публичные списки). Риск массового сбора номеров. Варианты: показывать после входа или по нажатию. Не менял — это продуктовое решение. |
| БИН и данные проверки | Только на время проверки | Хранятся без срока. Рекомендуется после решения оставлять статус, а БИН и примечание удалять через N дней. |
| E-mail | Да, для входа и списка администраторов | Другим не показывается. Оставить. |
| Сообщения в чатах | Пока идёт договорённость | Хранятся бессрочно. Нужен срок хранения. |
| Точные координаты | Нет, необязательны | Добавляются только пользователем. Оставить. |
| IP и журналы | — | Приложение их не сохраняет; журналы ведёт хостинг-платформа. |
| Удаление аккаунта | — | Отсутствует (см. п. 3.4). |

Лишних обязательных полей в формах не найдено: ИИН, документы и платёжные данные не запрашиваются.

## 5. Аудит сторонних SDK и внешних запросов

- Зависимости времени выполнения (`package.json`): интерфейсные библиотеки, `leaflet`, `recharts`,
  `drizzle-orm`, `zod`, `vinext`. Аналитики, рекламы, трекеров, виджетов соцсетей, платёжных и
  чат-SDK нет.
- Хосты в готовых страницах (проверено на локальном сервере): `images.unsplash.com` (11 демо-картинок на
  главной), ссылка на `geonames.org`, сам сайт. Адреса `w3.org` — это пространства имён SVG.
- Карты: `leaflet` загружает плитки `tile.openstreetmap.org` — сервер видит IP пользователя.
- Шрифт Manrope через `next/font`: в HTML нет запросов к `fonts.googleapis.com`.
- WhatsApp открывается только по нажатию на ссылку.
- Платформенные обработчики данных: вход ChatGPT, хостинг. Нужны их условия обработки данных.
- Только для разработки: `@openai/sites-vite-plugin`, `wrangler`.

Рекомендации: заменить демо-картинки Unsplash собственными (убрать передачу IP и зависимость от
лицензии), при росте нагрузки не ходить на общедоступный сервер плиток OpenStreetMap, а взять
провайдера с договором или собственный.

## 6. Тёмные паттерны

Искались: ложная срочность и дефицит («осталось», «только сегодня»), предвыбранные согласия,
«стыдящие» кнопки отказа, скрытая отмена, накрученные счётчики. **Не найдено.** Счётчики откликов
реальные (`response_count`), `defaultChecked` лишь восстанавливает черновик пользователя, баннер cookie
не подталкивает к выбору. Замечание: в интерфейсе есть формулировка «Позже подключим магазины и склады
… со скидкой» (`qoldan-client.tsx`, раздел будущих функций) — это анонс, не предложение, но его стоит
убрать, пока функции нет.

## 7. Скрытые платежи

Искались: платёжные SDK и интеграции, комиссии, тарифы, подписки, платное продвижение, предоплата.
**Не найдено.** Интерфейс прямо сообщает «Qoldan не принимает оплату» и «не удерживает комиссию»
(страницы объявлений, заявок, жилья, раздел безопасности). Если платные функции появятся: показывать
цену до действия, обновить оферту, условия возврата и политику данных, добавить тест на это.

## 8. Как не дать документам устареть

Запускайте `node --experimental-strip-types scripts/test-legal.mjs` вместе с остальными тестами. Тест
проверяет соответствие политики схеме БД и наличие согласий в формах.
