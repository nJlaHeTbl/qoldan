## 2. Порядок переезда (делает владелец или исполнитель по его прямому «да»)

2. В рабочей копии владельца:
   ```
   git remote add origin https://github.com/<владелец>/<репозиторий>.git
   git push -u origin main
   ```
   Отправлять только `main`: ветки `claude/*` уже в нём, лишние ветки на GitHub не нужны.
3. Открыть вкладку Actions и убедиться, что CI прошёл (тесты, типы, линтер ≤ 65, сборка).
4. В настройках репозитория: защита `main` (изменения через pull request, обязательный зелёный CI).
5. Секреты (Cloudflare и прочие) в репозиторий не класть. Если понадобится автодеплой — только через
