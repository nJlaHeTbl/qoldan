# Запуск и демонстрация Qoldan

Редакция от 14 ноября 2026. Публикацию сайта, миграции production-базы и `git push` выполняет только владелец.

## 1. Что готово

Каталог с фильтрами и картой, объявления, заявки «Мне нужно» (отклики, выбор исполнителя, завершение, отзыв),
жильё на сутки (галереи фото), бронирование аренды и акт передачи, чаты, отзывы, жалобы, апелляции и
модерация, проверка бизнес-профиля, три языка (RU / QAZ / EN), правовые страницы и баннер cookie.
Список проверенного — в [QA_CHECKLIST.md](../QA_CHECKLIST.md). Рост и первые пользователи — в [GROWTH.md](GROWTH.md), аудит и дорожная карта — в [ROADMAP.md](ROADMAP.md). Все автотесты и сборка проходят (см. README).

## 2. Перед публикацией (владелец)

> **Важно:** по поправкам 2026 года персональные данные пользователей из Казахстана должны храниться на территории
> РК. Текущая платформа (Cloudflare D1/R2) этого, скорее всего, не обеспечивает. Подходит для демо и закрытого теста;
> для публичного запуска — перенос в облако с регионом в Казахстане. Подробности и источники —
> [INFRASTRUCTURE.md](INFRASTRUCTURE.md).

Миграции production (только владелец, после резервной копии):

```bash
node node_modules/wrangler/bin/wrangler.js d1 migrations apply DB --remote
```

Для production нужен настоящий `wrangler.json` с реальным `database_id`: `wrangler.local.json` предназначен только для
флага `--local` и содержит нулевой placeholder.

## 3. Локальный запуск

```bash
npx pnpm@10 install --frozen-lockfile
node node_modules/wrangler/bin/wrangler.js d1 migrations apply DB --local --config wrangler.local.json --persist-to .wrangler/state
node node_modules/vinext/dist/cli.js dev --port 3000
```

Откройте http://localhost:3000. Вы входите как локальный пользователь с правами модератора.

## 4. Сценарий показа (5–7 минут)

1. **Главная.** Поиск, быстрые направления («Часто ищут»), переключатель языка RU / QAZ / EN, карточка «Жильё на сутки».
2. **Каталог.** Выберите область Жетісу, переключите «Список / Карта», нажмите «Рядом со мной», покажите метки «ДЕМО»
   и переключатель «Все / Реальные / Демо».
3. **Заявка «Мне нужно».** Создайте заявку, покажите её публичную страницу `/request/<id>` и кнопку «Поделиться».
   Дальше нужны два аккаунта на опубликованном сайте: отклик → выбор исполнителя → «Работа выполнена» → отзыв.
   На локальном dev-сервере второго пользователя нет, там это показывают тесты (`scripts/test-requests.mjs`).
4. **Жильё.** `/housing`: публикация с фото, галерея с выбором обложки, редактирование.
5. **Безопасность.** Жалоба на публикацию → кабинет модерации → скрытие → апелляция. Владелец не может сам вернуть скрытую
   публикацию.
6. **Правовая часть.** Подвал сайта, баннер cookie, строка согласия в формах, `/legal`.

Расскажите вслух главное: Qoldan не принимает оплату, не берёт комиссию, демо-карточки честно помечены.

## 5. Известные ограничения

- Заявку можно изменить, пока на неё не откликнулись; отклик можно снять, пока заказчик не выбрал исполнителя. Нет редактирования отзыва. Экспорт и удаление аккаунта есть в профиле.
- Документы на RU/KK/EN; казахская и английская версии — перевод для удобства (при расхождении действует русская), их нужно проверить носителю и юристу.
- Сообщения чатов, БИН и данные проверки хранятся без срока.
- Dev-сервер подменяет личность пользователя, поэтому многопользовательские сценарии проверяются тестами, а не кликами.
- `test-settlement-editor` проверяет права модератора через код маршрута, а не через заголовки живого сервера.
