# Qoldan: аудит готовности и дорожная карта

Редакция от 18 ноября 2026. Технический руководитель разработки — Claude. Публикацию, расходы, платежи и
юридически значимые шаги согласует владелец.

## 1. Аудит: что есть сейчас

Подсчитано по коду, а не по описаниям.

| Область | Состояние |
|---|---|
| Страницы | 10: главная (`app/page.tsx`), объявление, заявка, жильё, правовые (5), редактор карты |
| API | 35 маршрутов `app/api/**`: объявления, заявки, отклики и выбор исполнителя, бронирования и акт передачи, чаты, отзывы, жалобы, апелляции, модерация, проверка бизнеса, избранное, сохранённые поиски, загрузки, поддержка, показ телефона |
| База | 24 таблицы, 23 миграции (`drizzle/0000…0022`), внешние ключи и каскады, уникальные индексы против гонок |
| Тесты | 6 скриптов на настоящих обработчиках и SQLite: заявки и модерация, жильё, выбор исполнителя, создание отклика, правовая часть, права редактора карты. Браузерных (e2e) тестов и CI нет |
| Безопасность | Права на сервере по `viewer`, проверка ввода zod, блокировка обхода модерации, защита от гонок, заголовки безопасности, телефон скрыт от гостей, журнал показов |
| Правовая часть | Политика данных, оферта, возврат, cookie, согласия в формах, подвал. Тексты по коду, нужна проверка юриста РК |
| Языки | RU / QAZ / EN, казахский текст нужно вычитать носителем |

### Готово и проверено
Каталог, фильтры, карта; объявления и жильё с галереями; заявки «Мне нужно» (отклики, снятие отклика, выбор, завершение,
отзыв); бронирование аренды и акт передачи; чаты; жалобы, апелляции, модерация; проверка бизнеса; показ телефона по
кнопке с лимитами и согласием владельца.

### Работает частично
- Уведомления: есть в приложении, нет WhatsApp, SMS, e-mail.
- Поиск по расстоянию: «Рядом со мной» и радиус по координатам, без выбора произвольной точки.
- Фото: загрузка и проверка есть; автоматического сжатия и CDN нет.
- Бронирование: телефон заказчика и контакт владельца передаются сторонам брони (осознанно, нужен контакт); массовый сбор
  через брони ограничен лимитами создания.

### Не реализовано
Онлайн-торги, платежи и платное продвижение, подтверждение телефона (SMS), экспорт и удаление данных пользователя,
редактирование заявки, срок хранения чатов и БИН, e2e-тесты, мониторинг ошибок, резервные копии (настраиваются на
хостинге), PWA, сравнение объявлений, подписки на изменение цены.

### Технический долг
- `app/qoldan-client.tsx` — один файл около 10 700 строк: разрезать на экраны и хуки, пока есть тесты.
- 65 известных замечаний линтера (список в README); новых быть не должно.
- Многопользовательские сценарии проверяются тестами, а не кликами: dev-сервер подставляет одного пользователя.

Каждый этап: тесты, обновление политики данных и правил (проверяет `test-legal`), ревью перед объединением.

## 3. Критерии готовности к запуску

1. Все тесты, `tsc` и сборка проходят; новых замечаний линтера нет.
2. Нет персональных данных в публичных ответах API и HTML (проверяется тестом).
3. Все операции с деньгами, ставками и статусами проверяются сервером и устойчивы к гонкам (проверяется тестом).
4. Юрист РК проверил документы; реквизиты оператора заполнены.
5. Настроены резервные копии и мониторинг, описан порядок восстановления.
6. Пройден ручной сценарий с двумя аккаунтами на тестовом окружении.
7. Реальные платежи включаются только после отдельного решения владельца, договоров и юридической проверки.

## 4. Решения владельца (не выполняются без «да»)

Расходы на хостинг, базу, домен и сервисы; выбор платёжного провайдера; публикация на рабочий сайт; миграции рабочей
базы; юридическая форма оператора; текст правил аукциона после консультации юриста.
