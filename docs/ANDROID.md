# Qoldan на старом Android-телефоне

Для закрытого теста с друзьями: база и фото хранятся прямо в памяти телефона, то есть в Казахстане.
Для настоящего запуска лучше сервер в облаке с регионом в РК (см. [INFRASTRUCTURE.md](INFRASTRUCTURE.md)) —
у телефона нет резервного питания, а Android сам закрывает фоновые программы.

Что проверено: папка из шага 1 запускается с другого места на компьютере (20.11.2026) — 27 миграций, главная,
страница входа, код входа в журнале. **На самом телефоне не проверялось** — если на каком-то шаге ошибка,
пришлите её текст.

## Что нужно

- Android 7 или новее, 2 ГБ памяти и больше, 1 ГБ свободного места.
- Зарядка, подключённая постоянно, и Wi-Fi.
- Компьютер с этим проектом (для шага 1).

## 1. Собрать папку на компьютере

В папке проекта:

```
node scripts/pack-phone.mjs
```

Появится папка `release/qoldan-phone` (около 50 МБ): сервер, миграции базы, `start.sh` и `backup.mjs`.
Скопируйте её на телефон по кабелю в «Загрузки» (Download).

## 2. Termux на телефоне

1. Установите **Termux из F-Droid** (https://f-droid.org/packages/com.termux/). Версия из Google Play устарела.
2. Откройте Termux и выполните по очереди:

```
pkg update
pkg install nodejs-lts
node -v
termux-setup-storage
cp -r ~/storage/downloads/qoldan-phone ~/
```

`node -v` должен показать **v22.13 или новее** (нужен встроенный SQLite). Если версия старее —
`pkg install nodejs` вместо `nodejs-lts`. `termux-setup-storage` спросит доступ к файлам — разрешите.

## 3. Первый запуск

```
sh ~/qoldan-phone/start.sh
```

При первом запуске создаётся файл `~/qoldan-phone/.env` с секретом входа (никому не показывать и не
выкладывать), база — в `~/qoldan-data/`. Сайт работает, пока открыт Termux; остановка — `Ctrl+C`.

Проверка с другого устройства в том же Wi-Fi: узнать адрес телефона (Настройки → Wi-Fi → сеть → IP, например
`192.168.1.25`) и открыть `http://192.168.1.25:3000`. Объявления смотреть можно, **но войти так не получится**:
браузеры сохраняют вход только по защищённому адресу `https://`. Для входа — шаг 4.

## 4. Доступ из интернета с https

Самый простой способ без белого IP и настройки роутера — туннель Cloudflare. Во второй вкладке Termux
(свайп от левого края → New session):

```
pkg install cloudflared
cloudflared tunnel --url http://localhost:3000
```

В выводе появится адрес вида `https://что-то.trycloudflare.com` — его и даёте друзьям. Адрес меняется при каждом
перезапуске туннеля; постоянный адрес — через аккаунт Cloudflare и свой домен. Учтите: трафик идёт через
Cloudflare, хотя сами данные хранятся на телефоне.

## 5. Вход и модератор

SMS и e-mail для кодов пока не подключены, поэтому **код входа появляется в окне Termux** строкой
`"event":"auth_code_dev" … "code":"123456"`. На закрытом тесте его можно переслать другу.

Чтобы стать модератором, добавьте свой e-mail в `.env` и перезапустите сервер:

```
echo "QOLDAN_ADMIN_EMAILS=ваш@email" >> ~/qoldan-phone/.env
```

## 6. Чтобы телефон не выключал сайт

- Настройки → Батарея (или Приложения → Termux → Батарея): **без ограничений** для Termux.
- `start.sh` сам включает `termux-wake-lock` (в шторке появится уведомление Termux — не смахивайте).
- Автозапуск после перезагрузки: установите **Termux:Boot** из F-Droid, откройте его один раз, затем:

```
mkdir -p ~/.termux/boot
printf '#!/data/data/com.termux/files/usr/bin/sh\nsh ~/qoldan-phone/start.sh\n' > ~/.termux/boot/qoldan
chmod +x ~/.termux/boot/qoldan
```

- Постоянная зарядка изнашивает аккумулятор: если в настройках есть «ограничить заряд 80–85 %», включите.
  Вздувшийся аккумулятор — сразу отключить телефон.

## 7. Резервная копия (раз в день или перед обновлением)

```
node ~/qoldan-phone/backup.mjs --db ~/qoldan-data/qoldan.sqlite --images ~/qoldan-data/images --out ~/storage/downloads/qoldan-backups --keep-days 30
```

Копия появится в «Загрузках» → `qoldan-backups`. Переносите её на компьютер: при поломке телефона без копии
пропадёт всё.

## 8. Обновление

1. На компьютере снова `node scripts/pack-phone.mjs` и скопировать новую `qoldan-phone` в «Загрузки».
2. В Termux: остановить сервер (`Ctrl+C`), сделать резервную копию (шаг 7), затем:

```
cp ~/qoldan-phone/.env ~/qoldan.env.bak
rm -rf ~/qoldan-phone
cp -r ~/storage/downloads/qoldan-phone ~/
cp ~/qoldan.env.bak ~/qoldan-phone/.env
sh ~/qoldan-phone/start.sh
```

Новые миграции применятся сами; база и фото в `~/qoldan-data/` не трогаются.
