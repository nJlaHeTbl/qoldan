# Правила для агентов (Claude, Codex и других)

Читать перед любой работой с Qoldan. Текущее состояние — в [HANDOFF.md](HANDOFF.md) и [SAVEPOINT.md](SAVEPOINT.md).

## Без «да» владельца — нельзя

- `git push`, merge в `main` на GitHub, публикация сайта.
- Миграции и любые изменения production-базы и хранилища фото.
- Одно «да» — на одно действие, не на всё последующее.

## Никогда

- Не выводить и не коммитить секреты и токены. Репозиторий **публичный**.
- Не коммитить `.env*`, `.dev.vars*`, `release/`, резервные копии базы.
- Не переписывать историю `main` (без `--force`).

## Как работаем

- Один исполнитель на одни файлы. Каждый этап — своя ветка (`claude/…`, `codex/…`) и PR в `main`.
- После каждого этапа — строка в `SAVEPOINT.md` (что сделано, коммит).
- Перед коммитом: `node scripts/check.mjs` (без сборки: `--no-build`). Должно быть зелёным; предупреждений линтера не больше 65.
- Новая логика — с тестом в `scripts/` и регистрацией в `scripts/check.mjs`.
- Новые тексты ошибок сервера — с переводами KK/EN в `lib/server-messages.ts`; тексты интерфейса — RU/KK/EN.
- Новая таблица или поле с личными данными — обновить политику данных (тест `test-legal`).
- Локальная база для проверок — только `--local`.
- В конце коммита: `Co-Authored-By: <модель> <noreply@anthropic.com>` (для Claude).

## Общение

- С владельцем — по-русски, на «ты», коротко и простыми словами.
- Если что-то не проверено — так и сказать.
